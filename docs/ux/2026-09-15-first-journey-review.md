# Atlas Mobile：首次留学用户模拟走查

日期：2026-09-15。评审角色：第 3 智能体（中文用户体验）。

## 证据范围与结论

本轮是**源码静态走查 + 用户已经提供的真实手机截图评审**，不是实时真人测试、真机点击或模拟器 E2E。当前未使用设备、未登录用户账户、未创建身份或发送邮件。不能据此声称 App 已经能正常使用。

- 对照基线：team 工作树提交 `13e5401a655530853d3c2b537d4f1353d2b3db11`；相关源码最初读取自 `atlas-mobile-auth-fix`，已比对 team 的首页及认证界面。
- 真实截图：用户 14:54 登录后的首页，当前事项报 `Unable to load this information.`，下方同时声称已加载最新旅程。
- 网页端对照依据：用户已明确的产品规则——下一步清晰、已填信息复用、中文、解释前置条件、材料与办理步骤可执行。本轮未运行网页端，不宣称已完成网页/App 逐屏一致性核验。
- 判定：**NOT READY（面向留学用户的完整流程）**。修正文案和请求处理能改善壳层，但不能补齐当前不存在的建档、申请详情及写入流程。

严重级别说明：这里 P0 指“阻止本次可用流程交付”，不等同于安全漏洞等级。

## 首轮可直接落地的中文状态文案

以下是建议，不是对服务端根因的断言。动作只有在真实存在时才能显示。

| 场景 | 建议正文 | 动作 |
| --- | --- | --- |
| 当前事项加载中 | 正在获取你的下一步… | 无重复提交按钮 |
| 未分类的加载失败 | 暂时无法获取你的下一步。当前未能确认申请进度，请重试。 | 重新加载 |
| 确认的网络异常 | 网络连接不稳定，暂时无法加载。检查网络后再试。 | 重新加载 |
| 确认的会话失效 | 登录状态已失效，请重新登录后继续。 | 重新登录（实际清理并跳转） |
| 接口未接通/版本不支持 | 当前测试版服务尚未就绪，暂时无法查看下一步。这不是密码填写问题。 | 重试；不要引导反复注册 |
| 成功返回，`primary=null` 且 `completed=false` | 暂时还没有生成下一步。 | 仅在可靠建档状态和路由存在时提供“完善留学档案” |
| 成功返回，`primary=null` 且 `completed=true` | 当前事项已完成。 | 不据此声称整个留学旅程、签证或其他未确认阶段已完成 |
| 事项存在，但原生操作未实现 | 此步骤暂不能在 App 内办理。当前测试版仅支持查看。 | 无伪“继续”；跨网页跳转需要独立验证环境与身份 |
| 申请空列表 | 你还没有添加申请。 | 原生创建尚未实现时说明“当前版本暂不能新建申请” |
| 独立测试环境说明 | 这是独立测试环境，网站账号和资料不会自动同步。请使用测试账号，不要上传真实敏感材料。 | 注册前可见 |

不应出现：请求失败时显示“已同步”；在未知原因下说“密码错误”；在没有真实完成分母时显示进度百分比；将“无数据”当作“已完成”；把 mock 数据显示为学生真实资料。

## 首个真正可用流程：验收标准

这是未来交付门槛，不是本轮已通过的功能。桌面浏览器模拟的通过只能算 web render 验证；Android 需有独立运行的 native build 和设备/模拟器证据。

1. **首次打开 → 认证**：默认中文；测试环境身份边界清楚；注册、验证码/验证邮件（按实际机制）、返回 App、登录均无死路；失败可恢复；输入不会被无故丢弃；注册同意/说明在收集信息前可读。
2. **登录 → 下一步**：新用户看到“完善留学档案”，老测试用户回到真实未完成任务；请求错误不被当成新用户/空态；任何未确认身份不渲染旧用户信息。
3. **建档 → 确认**：分步只问必需内容；已有测试资料先匹配再让用户确认、修改；保存失败保留输入；重复点保存不产生重复档案；退出/重进仍保留服务端已保存数据。
4. **档案 → 第一条申请**：可选校或使用已有目标校；若推荐需付费 API，测试前单独确认预算，不能擅自花费；学校要求与用户背景对应；创建申请后列表和首页使用同一状态。
5. **申请 → 材料/下一步**：可打开详情、看到材料完整性和可执行步骤；上传失败可重试；不把未识别材料标绿；缺失材料有真实替代/补充入口；状态改变后返回首页和旅程同时更新。
6. **跨阶段一致性**：至少从新建档案至第一条申请的状态变化已验证；Offer、签证、行前、行政手续如未实现，显式列为未覆盖，不标“与网页一致”。前置条件必须沿用网页端共享契约而非复制一份独立规则。
7. **退出/恢复**：退出后 Android 返回键不能看到私人页面；二次登录不出现上一用户资料；网络断开、超时、401、403、后台/前台切换均呈现中文可恢复状态。
8. **视觉可操作**：小屏、大字体、键盘弹出、系统返回、读屏标签均检查；首屏能回答“我现在要做什么、为什么、点哪里”；不依赖用户发现基础故障。

### 发布判断

**不放行 APK 给用户试用：NOT READY。** 可以保存本轮源码修正并进入下一轮开发/测试；不能把“明确提示暂不能办理”、关闭无效按钮、纯逻辑测试通过解释成首个可用流程完成，更不能声称与网页端全流程一致。

本轮第 3 智能体完成了两轮模拟用户走查，并将发现直接反馈给开发和测试；没有冒充真人或真实真机体验。
